Tema Program :
program sederhana untuk mencatat dan mengelola data paket masuk berdasarkan nama barang, berat, dan kode wilayah. Program ini memiliki fitur menghitung jumlah paket, mencari paket berdasarkan kode, menampilkan statistik per wilayah, serta menyimpan dan memuat data dengan aman menggunakan exception handling.

cara menjalankan :
klik run pada vs code
lalu pilih fitur 1 (menambahkan data paket)
fitur 2 (menghitung otomatis jumlah paket yang masuk)
fitur 3 (mencari paket berdasarkan code dengan memasukkan code)
fitur 4 (menampilkan data paket setiap kode dengan total berat dan jumlah berat)
fitur 5 (menyaring berat paket sesuai jumlah minimum paket)
fitur 6 (menyimpan data yang blm ke save)
fitur 7 (mencari paket tanpa pandang kode)
fitur 0  (keluar dari terminal)
